# Chapitre pilote

Ce dossier accueille le contenu complet du **chapitre pilote** choisi pour la
tranche verticale (Jalon 1) : questions triées, difficulté étiquetée, explications
rédigées et relues. C'est le contenu qui sert à valider toute la chaîne de bout en
bout avant d'élargir aux autres chapitres.
